# Five Visualisations

## Project Overview
This project analyses employee data using Python, Pandas, and Matplotlib. Five visualisations are created to understand the data and communicate insights.

## Project Files
- `employee.csv` – Employee dataset.
- `main.ipynb` – Jupyter Notebook containing analysis and visualisations.
- `figures/` – Contains five saved chart images.

## Visualisations
1. Bar chart
2. Histogram
3. Scatter plot
4. Line chart
5. Box plot

## Requirements
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## How to Run
1. Open the project folder in VS Code.
2. Install the required libraries:
   `python -m pip install pandas matplotlib notebook`
3. Open `main.ipynb`.
4. Run all notebook cells.
5. View the generated charts in the `figures/` folder.

## Conclusion
The project uses five charts to communicate patterns and relationships in employee data. The findings should be interpreted carefully because the dataset is limited.
