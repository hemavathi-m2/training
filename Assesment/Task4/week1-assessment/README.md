# Week 1 Assessment — Employee Data Analysis

## Project Overview

This project analyses employee salaries and visualizes department-wise salary averages. It also examines employee distribution across cities.

## Project Structure

- `data/employees.csv` — Employee dataset
- `notebooks/employee_analysis.ipynb` — Analysis notebook
- `src/employee_analysis.py` — Python script
- `reports/findings.md` — Analysis findings

## Setup Instructions

Install the required libraries:

```bash
python -m pip install pandas matplotlib notebook nbconvert
```

Run the analysis script:

```bash
python src/employee_analysis.py
```

Open Jupyter Notebook:

```bash
python -m notebook
```

## Key Findings

1. The dataset contains 8 employees and 5 columns.
2. Karthik has the highest salary: ₹90,000.
3. Arun has the lowest salary: ₹30,000.
4. Chennai has the most employees: 4.
5. The project analyses department-wise salaries, city-wise employee counts, and salary distribution using charts.
